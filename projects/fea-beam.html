Independent project · Paris · Oct 2023 – Feb 2024

Finite Element Analysis of a Loaded Structure

AbaqusValidation on analytical solutionsCAD

Summary

A project to master finite element analysis end to end: model a loaded beam in Abaqus, run static and dynamic analyses, and post-process bending, stresses and strains. Each result was compared with the reference analytical solution before trusting the model.

On the bench

The habit I keep from this project: before any complex model, compute a case whose answer you know, measure the error and refine the mesh until it is under control. The figure below reproduces the idea with a small plane-stress solver: the finite element tip deflection is within 0.5 % of the Euler–Bernoulli value (the small difference is shear deformation, which beam theory neglects).

Key results

  • Static and dynamic analyses compared with analytical solutions
  • Mesh-convergence and validation methodology

Method & equations

Finite element system and element stiffness:

$$\mathbf{K}\,\mathbf{u}=\mathbf{f},\qquad \mathbf{K}=\sum_e\int_{\Omega_e}\mathbf{B}^{T}\mathbf{D}\,\mathbf{B}\,d\Omega$$

Analytical references for a cantilever of length \(L\), bending stiffness \(EI\), tip load \(P\):

$$\delta_{\text{tip}}=\frac{PL^{3}}{3EI},\qquad \sigma_{\max}=\frac{PL\,(h/2)}{I},\qquad \omega_n=\beta_n^{2}\sqrt{\frac{EI}{\rho A L^{4}}},\ \ \beta_1L\approx1.875$$
